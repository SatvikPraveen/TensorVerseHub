# Contributing

The full contributing guide lives in the repository root: [CONTRIBUTING.md](https://github.com/SatvikPraveen/TensorVerseHub/blob/main/CONTRIBUTING.md).

It covers:

- Ways to contribute (bug reports, features, notebooks, docs)
- Development environment setup (`make install`, pre-commit)
- Code style (ruff for linting and formatting, mypy for type checking)
- Running the test suite on Keras 3 and legacy Keras 2
- Notebook conventions
- Pull request process and commit message format
